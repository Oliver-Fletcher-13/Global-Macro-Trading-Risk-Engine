# Model Dictionary

**CAGR** — compound annual growth rate.

**Maximum drawdown** — largest fall from a previous portfolio peak.

**Sharpe ratio** — excess return relative to return volatility.

**Beta** — sensitivity of an asset/portfolio to benchmark movements.

**Tracking error** — volatility of active returns versus a benchmark.

**Information ratio** — active return earned per unit of tracking risk.

**DV01** — approximate dollar P&L from a 1 basis-point yield move.

**VaR** — a loss threshold at a stated confidence level over a stated horizon.

**Expected Shortfall** — average loss in the worst tail beyond the VaR cutoff.

**Delta** — approximate option-price sensitivity to the underlying asset.

**Gamma** — rate at which delta changes with the underlying.

**Vega** — sensitivity of an option to implied volatility.

**Theta** — sensitivity of an option to the passage of time.
