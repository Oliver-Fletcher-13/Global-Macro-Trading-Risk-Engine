# Reproducibility

The repository separates the project into three layers:

1. **Data** — `data/` contains the annual return and regime-engine datasets used in the workbook.
2. **Models** — `python/` contains readable reference implementations of the main calculations.
3. **Presentation** — `model/`, `figures/` and `report/` contain the integrated Excel workbook, charts and research documents.

The Python examples are intentionally transparent and are not a line-for-line export of every Excel formula. The Excel workbook remains the canonical integrated presentation of the project.
